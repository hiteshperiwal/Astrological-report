# Third-party data attributions

## World historical event corpus

Jyotish Lab can import the first 1,000+ exact-date records from `snauhaus/historic_events`, a large historical-events dataset. The repository states that its data is released under **CC BY-SA 3.0** and requests attribution to Nolan Hemmatazad / Wikimedia Commons. The sync script preserves source attribution in every imported record.
