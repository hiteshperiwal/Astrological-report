# Validation policy

Jyotish Lab separates three kinds of validation:

1. **Astronomical calculation validation** — deterministic checks on chart structure, Varga count, Nakshatra/Pada ranges, Shadbala component presence, Ashtakavarga dimensions, forecast horizon ordering, and reproducibility.
2. **Historical research validation** — mundane temporal holdout and control-window comparisons against the bundled event corpus. These quantify rule coverage/signal separation only.
3. **Forecast truth validation** — not claimed. Future astrological events cannot be established as empirically correct by this application without independently recorded, prospective outcome data and a pre-registered evaluation protocol.

All date-only mundane events are explicitly marked as noon proxies unless a documented time is supplied. Users should replace proxies with archival timestamps for research-grade event-chart work.
